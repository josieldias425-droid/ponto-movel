# Ponto Móvel

Painel administrativo do protótipo Ponto Móvel, conectado ao Supabase.

## Configuração

Crie `.env.local` com:

NEXT_PUBLIC_SUPABASE_URL=https://xisumqhkmxdivaogdtaa.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=SUACHAVEPUBLICA

O banco usa as tabelas `ponto_*` criadas no projeto Supabase do Ponto Móvel.

## Deploy

Importe este repositório no Vercel e configure as duas variáveis de ambiente antes do deploy.
